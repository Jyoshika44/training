⚙️ How The Recommendation System Works

Our algorithm evaluates five key dimensions to deliver a meaningful match percentage instead of random suggestions:

1. Skill Match (25%)

Jaccard similarity matching student's programming languages with project prerequisites.

2. Technology Match (25%)

Overlap between frameworks/tools known and project tech stack requirements.

3. Domain Match (25%)

Alignment between preferred specialization areas and project domain taxonomy.

4. Difficulty Fit (15%)

Calculates optimal learning stretch without overwhelming the student.

5. Duration Fit (10%)

Verifies estimated development schedule fits available semester time.
